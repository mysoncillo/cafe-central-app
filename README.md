# ☕ Café Central – Aplicación de pedidos

## Acerca del proyecto
Café Central es una aplicación web pensada para que los clientes de la cafetería consulten el menú y hagan sus pedidos desde su celular o computadora, sin filas ni confusiones.

## ¿Qué problema resuelve?
Actualmente los pedidos se toman de forma manual, lo que genera errores, retrasos y confusión. Con la aplicación, el cliente elige lo que quiere y la cafetería puede llevar un control claro de cada orden.

## Funcionalidades principales
- Consulta del menú.
- Visualización de precios.
- Registro de clientes.
- Selección de productos.
- Creación de pedidos.
- Consulta del estado del pedido.
